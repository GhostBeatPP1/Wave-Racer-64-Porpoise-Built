# Wave-Racer-64-Porpoise-Built
Romhack for Wave Race 64, adding playable dolphin and more

A fan made enhancement for Wave Race 64, featuring the Dolphin as a playable character (with alternate costume) as well as a few cheat codes:

| Cheat | Where to enter | Sequence |

| Big Head Mode | Main menu (Hold L) | ↑ ↑ ↓ ↓ ← → ← → |
| Free Roam—disables out-of-bounds penalties | Main menu (Hold L) | ← → ← → ↑ ↓ ↑ ↓ |
| Porpocalypse—aggressive dolphin opponents | Main menu (Hold L) | ↑ → ↓ ← ↑ → ↓ ← |


INSTALLATION

Start with an unmodified USA Wave Racer 64 ROM in .z64 format. 
Apply patch using a BPS compatible patcher.
Load the resulting ROM in your emulator or compatible N64 flash cart. Fresh-boot the game; do not load a save state from an older version.
This is the complete patch. No earlier patches are needed. The original game ROM is not included.


Codes can be combined. Repeating a code does will turn it off. Reboot the ROM without loading a save state to reset the codes.
